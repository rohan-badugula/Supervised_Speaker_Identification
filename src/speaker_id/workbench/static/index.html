Local setup

Playback, uploads, and reference labeling work without model downloads. Processing needs these local dependencies.

Install from the project folder

source .venv/bin/activate
python -m pip install -e '.[ecapa,dev]'
brew install ffmpeg

Enable initial model access

Accept the Community-1 conditions on Hugging Face, set HF_TOKEN in the server terminal, and restart the workbench. No token is entered or stored in this UI.

Open Community-1 model page ↗

The workbench currently processes on CPU. Browser playback depends on your file's codec; MP4/H.264 and common MP3 files are the safest starting formats.
