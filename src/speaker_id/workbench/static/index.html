    ON THIS MACHINE

    Local setup

    Import, playback and reference labeling work without model downloads. Analysis needs these local dependencies.

    Install from the project folder

    source .venv/bin/activate
python -m pip install -e '.[audio,dev]'
# Optional: add ECAPA with .[ecapa,dev]

    The audio extra includes a packaged FFmpeg fallback when no system installation is available.

    Enable initial model access

    Accept the Community-1 conditions on Hugging Face, create a read token, set HF_TOKEN in the server terminal, and restart the workbench. No token is entered or stored here. A configured token does not verify model access; Hugging Face can still reject the first download.
